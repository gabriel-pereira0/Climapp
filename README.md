# 🌤️ Climapp

Aplicativo de previsão do tempo desenvolvido com **React Native**, **Expo** e **TypeScript**, criado durante meus estudos de desenvolvimento mobile.

O projeto permite pesquisar cidades e visualizar informações atuais do clima, além da previsão para os próximos dias.

## 🚀 Funcionalidades

- 🔎 Pesquisa de cidades
- 🌡️ Temperatura atual
- ☁️ Condição climática
- 💧 Umidade
- 📈 Temperaturas mínima e máxima
- 📅 Previsão dos próximos dias
- 📱 Interface responsiva
- 🔄 Dados atualizados de acordo com a cidade selecionada

## 🛠️ Tecnologias

- React Native
- Expo
- TypeScript
- Expo Router
- React Hooks
- API de previsão do tempo

## 📂 Estrutura

O projeto utiliza **Expo Router** para navegação entre as telas e componentes reutilizáveis para exibição das informações climáticas.

## 🎯 Objetivo

Este projeto faz parte da minha evolução nos estudos de **React Native e TypeScript**, colocando em prática conceitos como:

- Componentização
- Props e tipagem com TypeScript
- Consumo de API
- Navegação com Expo Router
- Renderização dinâmica com `map()`
- `ScrollView` horizontal
- Organização de componentes
